# AI Vision — CNN Image Classification

## Required files
- `app.py`
- `requirements.txt`
- `cnn_image_classifier.keras` (downloaded from Google Colab)

Keep all three files in the root of your GitHub repository.

## Deploy
1. Create a GitHub repository.
2. Upload the three files above.
3. Go to https://share.streamlit.io and sign in with GitHub.
4. Create an app and choose `app.py` as the main file.
5. Deploy.

The model expects CIFAR-10-like images and resizes uploads to 32 × 32 RGB pixels.
Test accuracy in the training run was 70.84%. Everyday photos may perform differently.
